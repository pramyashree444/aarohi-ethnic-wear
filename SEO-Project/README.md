Aarohi Ethnic Wear – SEO Project

Project Overview

This repository documents a practical SEO audit and website optimisation project conducted on a fictional ethnic wear website, Aarohi Ethnic Wear.

The project demonstrates the application of SEO concepts, tools, technical checks, website optimisation, performance analysis and reporting.

Website: "Aarohi Ethnic Wear" (https://pramyashree444.github.io/aarohi-ethnic-wear/)

Project Type: Self-initiated SEO practice project
Prepared by: P. Ramyasri

Project Objectives

- Understand and apply practical SEO techniques.
- Conduct keyword research and map keywords to relevant website pages.
- Analyse competitor websites.
- Improve on-page SEO elements.
- Identify technical SEO issues.
- Evaluate mobile and desktop website performance.
- Verify website indexing and traffic measurement.
- Analyse the website's backlink profile.
- Document findings, changes and limitations.

SEO Activities Performed

1. Keyword Research

- Explored search interest using Google Trends.
- Compared relevant ethnic wear search terms in India.
- Reviewed keyword relevance and mapped terms to website pages.
- Explored Google Keyword Planner; further research was limited by a billing prompt.

2. Competitor Analysis

Reviewed competitor websites including Biba, Libas and Manyavar to understand their website structure, content and keyword positioning.

3. On-Page SEO

- Updated page titles and meta descriptions.
- Reviewed heading structure.
- Added canonical tags.
- Improved internal navigation.
- Applied relevant keywords to website pages.

4. Technical SEO

- Crawled the website using Screaming Frog SEO Spider.
- Reviewed HTTP response codes, page titles, meta descriptions and canonical tags.
- Checked content length and readability.
- Reviewed sitemap accessibility and Google Search Console status.

5. Website Performance

Used Google PageSpeed Insights to evaluate mobile and desktop performance.

6. Google Search Console

- Submitted the XML sitemap.
- Checked indexing status.
- Inspected URLs and performed live URL tests.

7. Google Analytics 4

- Installed the GA4 measurement tag.
- Verified Realtime activity.
- Reviewed events, traffic acquisition and landing-page reports.

8. Off-Page SEO

Used Ahrefs Free Backlink Checker to review backlink information for the website URL.

Tools Used

- Google Trends: Keyword research and search-interest comparison.
- Google Keyword Planner: Keyword research exploration.
- Screaming Frog SEO Spider: Website crawling and SEO audit.
- Google PageSpeed Insights: Website performance analysis.
- Google Search Console: Indexing and sitemap monitoring.
- Google Analytics 4: Website traffic and event measurement.
- Ahrefs Free Backlink Checker: Backlink analysis.
- GitHub Pages: Website hosting and project documentation.

Key Findings and Results

Website Performance

Latest PageSpeed Insights check: 13 November 2026.

Mobile

- Performance: 92
- Accessibility: 100
- Best Practices: 100
- SEO: 100

Desktop

- Performance: 99
- Accessibility: 100
- Best Practices: 100
- SEO: 100

These are Lighthouse lab results, not real-user field data. PageSpeed Insights did not provide sufficient real-user data for Core Web Vitals.

Google Search Console

- 8 indexed pages.
- 0 pages reported as not indexed in the checked Pages report.
- The sitemap remained publicly accessible, but Search Console continued to display "Couldn't fetch".
- A live URL test of the sitemap was successful. The sitemap reporting issue remained unresolved.

Google Analytics 4

- Realtime activity and events were verified.
- Page views, sessions, user engagement and scroll events were observed.
- The collected activity includes personal testing and should not be interpreted as genuine customer traffic or business performance.

Screaming Frog

- Website crawl and technical checks were performed.
- The crawl overview and issue-specific filters were recorded in the supporting workbook and screenshots.
- Findings included content-length and readability observations.
- The audit was conducted using the free version.

Backlink Analysis

- Ahrefs reported 0 backlinks and 0 linking websites for the checked website URL.
- The displayed Domain Rating of 94 relates to the GitHub hosting domain context and should not be treated as the independent authority score of the fictional website.

Project Limitations

- Aarohi Ethnic Wear is a fictional practice website, not a live commercial business.
- No actual products, transactions or customer enquiries were involved.
- Google Business Profile was not created because the business is fictional.
- Keyword search-volume and difficulty metrics were not fully collected.
- Google Keyword Planner research was restricted by a billing prompt.
- Search Console continued to show a sitemap fetch-status issue despite successful public access and live testing.
- GA4 measurements include test visits.
- No link-building campaign was implemented.
- Core Web Vitals field data was unavailable.
